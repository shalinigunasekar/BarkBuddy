# BarkBuddy - Stray Dog Donation & Adoption Platform

BarkBuddy is a production-ready Django application designed to bridge the gap between animal rescuers (Donors) and potential pet owners (Adopters).

## 🚀 Features
- **Dual User Roles**: Registered as either Donor or Adopter.
- **OLX-Style Listings**: Donors can list dogs with multiple images and health details.
- **Smart Filtering**: Filter by breed, location, age, and gender.
- **Formal Adoption Process**: Detailed application forms with Govt ID upload.
- **Internal Messaging**: Real-time-style chat once a request is accepted.
- **Notification System**: Instant alerts for application updates and messages.
- **Reporting System**: Users can flag fake listings or abuse.

## 🛠️ Tech Stack
- **Backend**: Python 3.11, Django 5.0
- **Database**: SQLite (Dev) / PostgreSQL (Prod)
- **Frontend**: Bootstrap 5, Vanilla JS, HTML5/CSS3
- **Image Processing**: Pillow
